全链路

四个端各有自己的程序，由当地的 Agent 执行。数据只往一个方向走，内网里没有任何东西回传到外网，所以 Mac 自己记录打包过哪些版本。

一个批次怎么进内网

批次是跨越人工拷贝的唯一格式。从查版本到转正，有四处要等你确认，其余步骤由 Agent 调脚本完成。

数据源怎么把关

  • 外层 .tar.sha256 只负责发现拷贝损坏。每个包的大小和 sha256 记在 batch.json 里，由 stage 逐个核对。
  • 同一工具、版本、平台再次出现但 hash 不同，stage 拒绝。同一批次重复 stage，不产生任何变化。
  • first_published_at（首次上架日期）由数据源记录，后续批次不会改写。

用户说“更新”

用户端 skill 把“更新”当作查看请求。Agent 读清单、查本机版本，只把需要更新的工具列出来，然后停下等用户选。

同一个命令在 PATH 上有多份时，以实际生效的那份判断版本，被遮蔽的只提示路径和版本。本地版本比清单还高时如实说明，不自动降级。

安装与切换版本

全新安装和更新走同一条路径。前四步只碰新的版本目录，任何一步失败就删掉新目录，现有版本不受影响。

版本目录加切换指针，解决了 Agent 更新自己的问题：Windows 不能覆盖正在运行的 exe，Linux 上也不该改正在用的文件。

Windows 上结构相同：%LOCALAPPDATA%\agent-tools\<id>\current 是目录联接（junction），入口目录只在首次安装时加入用户 PATH。两个平台都不需要管理员权限。

本周工具推荐

用户问“本周有什么新工具”时，Agent 以今天为终点往前取 7 天，按清单里的两个日期分类。工具描述只用清单里的文字，不用模型自己的知识补充。

  • 本周更新：claude-code、codex。最新版本发布于 11-07，在窗口内；首次上架是 10-27，不在窗口内。列成一张表，标注本机是否已安装、要不要更新。
  • 本周新工具：ripgrep。首次上架是 11-07。每个新工具一张卡片，写功能、亮点和适用场景，最后问要不要安装。

用滚动 7 天，不用自然周：批次常在周五发布，按自然周算，到周一就空了。窗口内没有内容时，展示最近一批并标明日期。

首次部署

Mac 上生成一个部署包，里面附一份 INSTALL.md。你把同一个包拷到服务器和中转机，对两台机器的 Agent 说同一段交接话。每个 Agent 只问你一次这台机器是什么角色，你确认后，它自己做完本机的部署。

  1. Mac：对 Agent 说“按 tool-source/deploy/INSTALL.md 部署”。它问一次身份和内网地址，然后运行 build-packs.sh、安装 fetch skill，最后给出部署包路径和交接话。
  2. Linux 数据源：贴上交接话。Agent 问一次身份，问话里说明会自动安装缺少的软件、启用 nginx 和 sshd、放行 443 和 22。你确认后，它依次运行 check、install、verify：授权包里的中转机公钥，把 SSH host 公钥放到 HTTPS 上，最后删除部署包。
  3. Windows 中转机：贴上同一段交接话，确认身份后，Agent 依次运行 install、test、publish。它经 HTTPS 取回 host 公钥、装好中转机私钥、发布只含用户端 skill 的部署批次，然后复制出 client-bootstrap.md，删除部署包。数据源还没部署好时，install 直接退出，不留改动。
  4. 用户 VM：你把 client-bootstrap.md 发给用户，用户交给自己的 Agent 执行，之后就可以说“更新工具”。

CA 私钥和中转机 SSH 密钥都在 Mac 生成，之后每次打包复用。服务器证书每次打包重新签发。部署包里有服务器私钥和中转机私钥，所以不能拷到用户 VM，两台机器部署完都会删掉它。

升级时，让 Mac 重新打包，再对两台机器各说一次交接话。数据源上已经是同一版本的 skill 时，中转机跳过发布。

已经去掉的环节

11-09 和 11-11 各做过一轮减法，下面这些在图里都没有了：

  • 部署时手工传值（11-11）：不再在服务器和中转机之间抄 host key 指纹和中转机公钥，三份部署包和五份说明合成了一个包、一份 INSTALL.md。
  • 回滚：数据源和用户端都不提供。转正前有预发布验证，安装前有试运行；转正后发现问题，发新批次修复。
  • 批次内的 SHA256SUMS：中转机不再解压整个批次重算哈希，包内容交给数据源 stage 核对。
  • manual 类型：只收录解压后就能运行的工具。
  • 其他：Claude Code 的 GPG 签名核对、自动查找上游 .sha256、stage --replace、中转机的 list 命令。
